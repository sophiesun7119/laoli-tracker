# laoli-tracker

独立运行在 Mac 上的老李视频研究工具，计划用于检查新视频、生成逐期总结、保留股票观点变化，并按最新有效的明确价格条件提醒。

## 当前状态

项目处于规划阶段，尚未实现视频处理、行情检查或通知功能。目前仓库包含项目说明、三阶段计划和本地数据忽略规则。第一阶段将在文件架构确认、频道与首批视频选定后开始。

完整范围、文件架构和验收标准见 [plan.md](plan.md)。

## 计划中的处理流程

1. 检查频道，发现尚未处理的视频。
2. 优先获取带时间戳字幕；没有可用字幕时，在 Mac 上转录音频。
3. 生成每期总结，提取股票观点、价格条件、限定词和来源片段。
4. 对比历史记录，保存变化并更新当前有效观点。
5. 根据有效条件检查行情，生成提醒预览或通知。

每条观点都应保留原句、视频链接和片段时间戳，方便回看核对。

## 三个阶段

| 阶段 | 目标 | 主要交付 |
| --- | --- | --- |
| A：验证提取 | 手动处理 3–5 期指定视频，验证内容质量 | 总结模板、观点卡片、逐期总结、观点变化对比 |
| B：完整手动版 | 一句话启动整套处理流程 | 增量处理、SQLite 存储、观点汇总、提醒预览、失败恢复 |
| C：自动运行版 | 定时检查视频和价格 | 无人值守 AI 执行、交易时段调度、通知去重、补扫与备份 |

第一阶段通过聊天完成总结与观点提取。无人值守 AI 执行方式在自动化阶段单独确定。Mac 关机或休眠期间不会运行本地任务，恢复后应补扫遗漏视频。

## 观点更新原则

- 明确修改同一条件时，以新条件替代旧条件，并保留历史。
- 仅提到股票或当前股价，不覆盖已有条件；未提及的股票保留来源日期。
- 买入价、卖出价、估值目标和个人成交价分别记录。
- 不同时间尺度、操作或前提可以并存。
- 模糊、矛盾或无法核实的表达列为待核对，不自动启用提醒。
- 补处理旧视频时，不用旧观点覆盖更新的有效观点。

项目用于记录与提醒，不执行交易。
